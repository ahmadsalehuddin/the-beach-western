# The Beach Western and Chinese Food Muslim

An ordering prototype for a restaurant: customers add an order and get a receipt, and staff update the menu, including uploading dish photos.

Coursework for **ISP550 Information Systems Engineering**, Bachelor of Information Technology (Hons.), Universiti Teknologi MARA (UiTM), 2021. Group project.

## Stack

JSP with JSTL SQL tags, a servlet for menu updates with file upload (Apache Commons FileUpload and IO, jars included), Apache Derby (Java DB). A NetBeans Ant web project, deployed on GlassFish.

## Running it

Open the folder in NetBeans with GlassFish, start Java DB, and create a database named `thebeachwestern`.
